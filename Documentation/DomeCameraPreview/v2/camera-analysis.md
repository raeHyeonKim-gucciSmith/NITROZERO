# NITROZERO — Dome camera preview v2

15초, 1280×720, 30fps. 원본 Unity 씬에 적용하지 않고 별도 복사본에서 카메라 동작을 렌더링한 무음 프리뷰입니다. 최종 라이팅·차량 물리·사운드 작업 전의 구도 검토용입니다.

## 길이와 편집 판단

전체 3분 중 15초는 약 8.3%입니다. 초반 장소 소개에 4.5초, 출차 이후 액션에 10.5초를 배분했습니다. 12초로 더 줄이면 돔을 알아볼 시간과 마지막 차량 통과 동작이 짧아집니다. 현재 요청한 구도를 모두 보여주는 데에는 15초가 적절하다고 판단했습니다. 이는 이번 시퀀스를 위한 편집 판단입니다.

| 시간 | 카메라 구성 | 역할 / 참고 |
|---|---|---|
| 0–2초 | 돔과 지구를 함께 보며 느린 가로 이동 | 기존 첫 영상의 장소 소개 |
| 2–4.5초 | 도로 가까운 시점에서 위로 틸트 | 돔을 정면으로 드러냄. 이전 프리뷰의 반대 방향을 수정 |
| 4.5–6.3초 | 돔 출구를 내려다보는 탑뷰 | 차량이 빠르게 나오는 순간과 진행 방향 제시 |
| 6.3–8.3초 | 높은 사선에서 두 차량을 추적하며 낮아짐 | 새 트레일러 6–7초의 공간감 활용 |
| 8.3–10초 | 차량 앞쪽 사선의 낮은 추적 | 차체와 노면을 가까이 보여 속도감 강화 |
| 10–12초 | 뒤집힌 추적 구도에서 수평으로 회복 | 새 트레일러 0–3초의 롤 회전 활용. 장소 소개 후 한 번만 사용 |
| 12–15초 | 노면 고정 시점 → 차량 아래 통과 → 후방으로 회전 | 기존 다섯 번째 영상의 의도. 통과 중 잠깐 속도를 낮추고 출구에서 다시 가속 |

## 레퍼런스 해석

사용자 트레일러를 브라우저에서 확인했습니다. 0–3초의 특징은 뒤집힌 도로 구도에서 수평으로 돌아오는 롤 회전이며, 6–7초는 높은 사선 추적입니다. 다른 구간의 전방 이동 촬영과 낮은 근접 추적도 참고했습니다. 원본 영상·로고를 삽입하지 않고 카메라 움직임을 재구성했습니다.

영화 F1의 촬영진은 관객이 속도와 중력, 위험을 느끼게 하기 위해 실제 차량에 작은 카메라를 설치하는 방식을 선택했습니다. 또한 Grand Prix의 항공 촬영과 회전 가능한 차량 장착 카메라를 참고했다고 설명합니다. 여기에서는 그 원리를 장소를 읽는 넓은 구도와 차체·노면 가까이의 구도를 번갈아 배치하는 방식으로 해석했습니다. 180도 롤은 모든 레이싱 영화에 공통적인 규칙이 아니라 이번 게임 트레일러에서 가져온 스타일 요소입니다.

## 범위

원본 Assets의 씬·타임라인·Cinemachine 설정은 수정하지 않았습니다. Library 아래 분리된 프로젝트에서 런타임 카메라와 차량 위치를 움직였습니다. 프리뷰에서만 지형의 반복 체크 패턴을 완화하고 색상·렌즈 효과를 조정했습니다. 실제 차량 물리 주행이나 최종 영화 품질의 렌더가 아닌 카메라 동선·길이·편집 리듬 확인용입니다.
