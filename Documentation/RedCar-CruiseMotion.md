# Red_Car 기본 고속 주행 연출

`Assets/Prefabs/Red_Car.prefab`에 `TrailerCruiseMotion`을 연결했습니다.
`Assets/01RAEHYEON/RaehyeonCar.unity`의 연결된 Red_Car 인스턴스에도 적용됩니다.

## 확인 방법

1. Unity의 스크립트 재컴파일이 끝나면 RaehyeonCar 씬을 엽니다.
2. Red_Car를 선택하고 Play를 누릅니다.
3. 차체와 바퀴가 함께 보이는 가까운 각도에서 출렁임을 확인합니다.
4. Trailer Cruise Motion의 Suspension Intensity는 느린 차체 출렁임,
   Vibration Intensity는 빠른 잔떨림의 강도입니다. 기본값은 각각 0.3과 1입니다.
   재생 중 수정한 값을 유지하려면 기록한 뒤 재생을 종료하고 다시 입력하세요.

## 기본값과 범위

- 240 km/h 기준의 즉시 바퀴 회전. 정지/가속 대기 없음.
- 느린 차체 상하 진폭 0.001, 피치 0.035도, 롤 0.025도. 기본 주파수 0.9 Hz.
- 빠른 상하 잔진동 진폭 0.00025, 회전 잔진동 0.008도.
- 길이 값은 차량 루트의 로컬 단위이며, 루트 배율이 1이면 미터 기준입니다.
- 네 바퀴는 원래 평탄 노면 접지 위치를 유지하고 차체가 그 위에서 움직입니다.
  실제 지형 추적, 물리 서스펜션, 독립적인 요철 충격은 이번 구현에 포함하지 않았습니다.
- 루트의 전진 이동은 스플라인 연결 단계에서 담당합니다.
  Speed Kph는 차체 진동용 속도, Wheel Speed Kph는 바퀴 회전용 속도입니다.
  두 값 모두 차량 위치를 이동시키지 않습니다.

## 바퀴 속도와 핸들 조향

- Wheel Speed Kph: 0~600. 0.1 등 소수 입력으로 느린 회전이 가능합니다.
  0은 바퀴 회전 정지이며 차체/경로 이동을 정지시키지 않습니다.
- Wheel Radius: 회전 속도 환산에 사용하는 타이어 반지름(기본 0.19m).
- Min / Max Handle Angle: 핸들 입력의 허용 범위, 기본 -360~360도.
- Wheel Angle At 360: 핸들 360도에 대응하는 실제 앞바퀴 각도, 기본 30도.
- Steering Wheel Angle: 직접 지정하는 현재 핸들 각도. 양수 우회전, 음수 좌회전.
- Steering의 Mode: Normal 0.8초 / DriftCounter 0.35초 / Recovery 1초.
- Start / Target Handle Angle: 시작각/목표각. 허용 범위 안으로 제한됩니다.
- Override Duration을 켜면 Custom Duration으로 시간을 직접 지정합니다.
- Easing: 시작과 끝에서 부드러워지는 곡선. 기본 곡선에는 튕김이 없습니다.
- Play에서 '조향 실행' 버튼을 누르면 설정된 시작각부터 움직입니다.
  '현재 각도에서 조향 멈춤'은 해당 각도를 유지합니다.
- Recovery도 목표각을 직접 지정합니다. 직진 복귀는 0도입니다.
- 앞바퀴 2개는 같은 각도로 꺾이고, 뒷바퀴는 굴러가는 회전만 적용합니다.
- 별도 핸들 모델을 회전시키는 기능은 포함하지 않습니다.

## 스플라인 자동 조향

1. Red_Car의 Trailer Cruise Motion에서 Automatic Steering을 켭니다(기본 켜짐).
2. Steering Spline에 차량이 따라갈 Unity Spline Container를 연결합니다.
3. 컨테이너에 여러 경로가 있으면 Steering Spline Index로 선택합니다(첫 경로 0).
4. Manual Steering Weight는 기본 0으로 둡니다. 0은 자동, 1은 기존 수동 핸들각입니다.

차량 루트의 현재 위치에서 가장 가까운 경로 지점을 찾아 곡률을 계산합니다.
경로를 월드 좌표로 변환하므로 경로 오브젝트 배율도 반영합니다.
곡률과 휠베이스로 앞바퀴 각도를 구하며 차체의 진행 방향이나 위치 자체는 수정하지 않습니다.
실제 이동과 차체 방향은 별도의 스플라인 이동 기능이 담당해야 합니다.
경로가 없거나 유효하지 않으면 기존 수동 조향을 사용합니다.

- Steering Look Ahead: 커브를 미리 보는 거리, 기본 0.3m.
- Steering Smoothing Distance: 경로 주변을 평균내는 거리, 기본 1m.
  시간을 누적해 보간하지 않으므로 같은 위치/설정에서는 같은 조향이 나옵니다.
- Steering Wheelbase: 0이면 연결된 바퀴의 앞뒤 간격을 자동 측정합니다.
  0보다 크면 직접 지정한 월드 미터 값을 사용합니다.
- Automatic Steering Strength: 자동 조향 강도, 기본 1.
- Max Automatic Wheel Angle: 실제 타이어 자동 조향 한계, 기본 30도.
  최종 핸들 입력 허용 범위도 적용됩니다.
- Use Spline Progress: 켜면 가장 가까운 지점을 찾는 대신 Spline Progress(0~1)를 사용합니다.
  교차하는 경로에서는 이동 컨트롤러가 이 진행도를 함께 지정하도록 연결하세요.
- 핸들 조향 실행 버튼은 Manual Steering Weight를 1로 전환합니다.
  다시 자동으로 돌아오려면 0으로 설정하세요.

Timeline 클립의 Manual Steering Weight도 0이면 자동 주행, 1이면 수동 조향입니다.
Automatic Blend In / Out(기본 0.2 / 0.5초)으로 클립 양 끝에서 자동과 수동을 부드럽게 전환합니다.
두 전환 시간의 합이 클립 길이보다 길면 비율을 유지하며 클립 길이에 맞춥니다.
복귀 대상은 0도가 아닌 그 시점 경로의 자동 조향각입니다.
새 촬영 Timeline 생성 버튼의 기본 주행 클립은 수동 비중 0으로 생성됩니다.
기존 수동 클립은 기본 수동 비중 1을 사용하므로 필요에 따라 변경하세요.
평상시 자동 주행을 유지하려면 차량의 수동 비중도 0으로 두세요.

## 촬영 시간

- 기본값은 Play 시작 시점부터의 시간을 사용합니다.
- 전용 Timeline 트랙이 없을 때 Shot Director는 Play 중 기본 주행 시간만 연결합니다.
- Use Manual Time을 켜면 Manual Time 값으로 특정 프레임의 주행 자세를 확인할 수 있습니다(Play 중).
- Time Offset과 Motion Seed는 차체 떨림의 위상을 바꿉니다.
- Play 중 일반 인스펙터의 바퀴 속도 변경은 회전량을 누적해 회전 자세가 튀지 않습니다.
  Manual Time 또는 단순 Shot Director 모드에서 속도를 변경하면 절대 시간으로 재계산됩니다.

## Timeline 사용법 (편집 모드 스크러빙 지원)

1. 씬의 Red_Car 선택 → Trailer Cruise Motion 하단의 '이 차량의 촬영용 Timeline 만들기'.
2. 저장 위치를 선택합니다. 5초 기본 주행 트랙과 차량 연결이 만들어집니다.
3. 생성된 촬영 오브젝트의 Playable Director를 Timeline 창에서 엽니다.
4. Wheel Speed & Steering 트랙에 Trailer Cruise Clip을 추가하거나 기본 클립을 복제합니다.
5. 클립을 선택해 Wheel Speed Kph, Steering의 상태/시작각/목표각을 설정합니다.
6. Timeline의 Preview를 켜고 재생 헤드를 이동하면 차체와 바퀴 자세를 확인할 수 있습니다.

기존 Timeline에서는 Trailer Cruise Track을 추가하고 Red_Car의 TrailerCruiseMotion을
트랙 바인딩 칸에 연결합니다. 한 차량에는 전용 트랙 하나를 사용하세요.
별도 Shot Director 필드 연결 없이 트랙 바인딩만으로 작동합니다.
전용 트랙이 제어하는 동안 일반 인스펙터의 조향 실행 버튼은 비활성화됩니다.

- 클립 시작부터 프리셋 시간 동안 조향한 뒤 목표각을 유지합니다.
- 클립 길이가 조향 시간보다 짧으면 해당 시점에서 잘립니다.
- 클립을 늘려도 조향 시간은 프리셋/Custom Duration 값으로 유지됩니다.
- 다음 클립의 시작각을 이전 클립의 최종각에 맞추면 연결이 부드럽습니다.
- 클립 사이 빈 구간에서는 차량의 수동 비중을 사용합니다. 기본 0이면 자동 조향,
  경로가 없거나 수동 비중 1이면 직전 수동 조향각을 유지합니다. 바퀴 속도는 차량 기본값입니다.
- 바퀴 속도는 각 클립에서 일정하며, 이전 클립과 빈 구간의 회전량까지 합산합니다.
  따라서 속도가 다른 클립으로 넘어가도 회전 자세가 튀지 않고 역방향 탐색도 재현됩니다.
- 겹침 블렌딩은 지원하지 않습니다. 겹치면 나중에 시작한 활성 클립이 우선합니다.
- Timeline 정지/그래프 해제 시 원래 차체·바퀴 자세를 복원합니다.
- 고속 회전은 촬영 프레임레이트에 따라 느리거나 역회전처럼 보일 수 있습니다.
  최종 속도감은 촬영의 모션 블러 설정과 함께 확인하세요.

`Assets/01RAEHYEON/Timeline/RedCar_SteeringSample.playable`에는
일반 → 드리프트/카운터 → 정렬과 0.1 / 600 / 120 km/h를 비교할 수 있는 예제가 있습니다.
사용하려면 Playable Director에 넣고 트랙에 Red_Car를 바인딩하세요.

## 구조와 호환성

Red_Car 바로 아래에 원점/무회전/배율 1의 CruiseBodyMotion을 추가했습니다.
기존 Mesh, CustomParts, BoosterDeploymentRoot, WingDeploymentRoot가 그 아래에 있습니다.
원래 부품의 로컬 자세와 참조 ID는 유지했습니다.
기존 RaehyeonCarWheelSpin은 이 프리팹에서만 비활성화하여 바퀴 회전 중복과 S키 정지를 방지했습니다.
변형 스크립트는 수정하지 않았으며 기존 부품에 계속 적용됩니다.
새 주행 컨트롤러는 LateUpdate에서 마지막으로 차체/바퀴 자세를 적용합니다.
조향은 이미 이 컨트롤러에 통합했습니다. 추후 바퀴 자체의 변형을 추가할 때는
이 컨트롤러의 바퀴 자세 계산과 통합해야 합니다.
CruiseBodyMotion은 전용 오프셋이므로 직접 위치/회전 애니메이션을 넣지 마세요.

## 검증

- 현재 프로젝트의 런타임 전체 소스를 Unity 제공 C# 컴파일러로 컴파일: 성공.
  기존 HUD 스크립트의 obsolete 경고 2개만 발생.
- Unity 6000.3.18f1 별도 테스트 프로젝트: 절대 시간 재현, 바퀴 회전 재현,
  루트 이동/회전/균일 배율에서 접지 유지, 차체 진폭 한계,
  강도 0, 비활성화 원복 및 재초기화 검증 통과.
- 프리팹 추가 ID 중복 및 연결 대상 존재 여부 검증 통과.
- 추가 기능: Unity의 실제 Timeline 그래프에서 프리셋 시간, 임의 시간 탐색,
  속도 변경 경계의 회전 연속성, 빈 구간 처리, 정지 원복 검증 통과.
  0.1/600 km/h 및 좌우 반전된 모델의 앞바퀴 조향·뒷바퀴 유지도 검증했습니다.
- 실제 Red_Car 화면의 미감과 부스터 변형 동시 재생은 시각 검증하지 못했습니다.
- 자동 조향 추가 검증: 직선/좌우 곡률, 경로 배율, 최근접 위치, 자동/수동 혼합,
  임의 시간 재평가, 실제 Timeline에서 커브 각도로 복귀, 경로 미연결 시 기존 수동 동작 통과.
