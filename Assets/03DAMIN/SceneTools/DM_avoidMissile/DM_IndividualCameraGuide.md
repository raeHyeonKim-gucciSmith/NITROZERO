# DM_avoidMissile — 카메라별 개별 촬영

Hierarchy의 DM_CinematicDirector를 선택합니다. DMCinematicDirector 인스펙터 맨 위에서 조절합니다.

## 조절할 값

- 촬영 모드: '전체 자동 전환'은 기존 컷 전환, '개별 카메라 촬영'은 선택한 카메라만 유지합니다.
- 촬영 카메라 번호: 1~10. 번호 변경 뒤 다시 재생하면 적용합니다.
- SHOT별 촬영 구간 사용: 켜면 선택한 카메라에 저장된 시작/종료 시간을 사용합니다. 끄면 예전 공통 시작/종료 시간을 사용합니다.
- SHOT별 출발 위치 적용: 켜면 촬영 시작 시 빨간차가 지정한 월드 X에 오도록 차량 6대·미사일 경로·카메라를 같은 거리만큼 옮깁니다. 재생 시작에 한 번만 적용하며 촬영 도중에는 이동시키지 않습니다.
- 촬영 시작/종료 시간: 전체 연출 시간표 기준입니다. 각 SHOT의 값을 인스펙터에서 따로 조절할 수 있습니다. 원래 20초 액션 시간표는 바꾸지 않습니다.
- 촬영 시작 시 빨간차 X (m): DM 직선 도로 안에서 구간의 위치를 조절합니다. 다른 차량의 상대 간격과 높이·차선은 유지됩니다. 정지 상태의 차량 Transform은 옮기지 않습니다.
- 구간 반복 재생: 테스트용입니다. 종료 후 지정한 대기 시간을 거쳐 0초부터 준비 재생을 다시 시작합니다. 녹화할 때는 끄는 편이 편합니다.
- 현재 기본은 SHOT별 구간·출발 위치 사용입니다. 예전 공통 0~20초 값은 보존하지만 SHOT별 구간을 켜면 사용하지 않습니다. 카메라 번호와 반복 여부는 사용자가 저장한 값을 유지합니다.

## 촬영 순서

1. 정지 상태에서 카메라 번호와 시작/종료 시간을 정하고 Ctrl+S로 저장합니다.
2. Play하면 처음부터 같은 차량·미사일 연출이 재생됩니다. 시작 시간을 10초로 정했다면 처음 10초는 준비 재생이며 인스펙터에 남은 시간이 표시됩니다. 연기 상태를 만들기 위해 즉시 점프하지 않습니다. 출발 위치를 옮긴 뒤의 준비 재생은 맵 밖일 수 있습니다. 준비 화면은 녹화본에서 제외하고 '촬영 구간 재생 중'부터 사용합니다.
3. 시작 시간부터 '촬영 구간 재생 중'으로 표시됩니다. 종료 시간에 차량 연출과 VFX 재생을 멈춥니다. Unity 전체의 Pause나 Time.timeScale을 바꾸는 방식은 아닙니다.
4. Unity Recorder 또는 화면 녹화 도구로 Main Camera/Game 화면을 녹화합니다. 이 기능 자체는 MP4를 자동 생성하거나 녹화 도구를 자동 시작/종료하지 않습니다. 시작 프레임을 놓치지 않으려면 Play 시작부터 녹화하고 준비 구간을 편집에서 자르는 방법이 간단합니다.
5. 다음 번호를 선택하고 '변경값으로 처음부터 다시 재생'을 눌러 같은 액션을 다른 카메라로 촬영합니다. Play 중 설정은 종료 후 되돌아갈 수 있으므로 유지할 설정은 정지 상태에서 저장하세요.

## 바뀌지 않는 것

- 기존 맵·달 지형·도로·조명·색감·차량 프리팹은 변경하지 않습니다.
- 현재 배율 8의 주행 속도와 20초 액션 시간표는 그대로입니다. 카메라별로 촬영 장소가 달라져도 차량·미사일의 상대 움직임은 같습니다.
- 시작/종료 범위는 현재 전체 길이 이내로 제한합니다. 20초를 넘겨 입력한다고 액션이나 도로가 늘어나지는 않습니다.
- 준비 재생은 연기 생성 시간을 확보하지만 GPU 파티클 노이즈까지 매번 픽셀 단위로 동일하다고 보장하지는 않습니다.

## 카메라별 주의

- 01: 고정 카메라. 차량이 지나간 뒤에는 빈 도로가 나올 수 있습니다.
- 02/06/07: 기존 카메라 이동이 끝나면 마지막 구도를 유지합니다. 원래 컷 시간이 끝났다고 시작 구도로 갑자기 돌아가지 않습니다.
- 07: 발사 전은 장착된 미사일, 발사 후는 실제 발사 미사일을 촬영합니다.
- 08: 개별 모드에서는 하나의 기본 구도를 유지합니다. 자동 모드의 부스트 전용 구도로 갑자기 전환하지 않습니다. 부스트 시 카메라 지연은 유지합니다.
- 10: 실내 구도는 미완성입니다. 개별 모드에서는 요청한 10번을 그대로 보여주므로 차체나 지붕에 가릴 수 있습니다. 전체 자동 모드에서는 기존대로 탑뷰로 대체합니다.

전체 자동 전환으로 돌아가려면 촬영 모드만 바꾸고 다시 재생하세요. 10개 카메라를 동시에 10개 파일로 저장하는 기능은 아닙니다.
