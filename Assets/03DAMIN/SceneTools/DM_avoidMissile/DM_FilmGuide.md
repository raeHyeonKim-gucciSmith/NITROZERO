# DM_avoidMissile 전체 촬영

대상은 Assets/03DAMIN/DM_avoidMissile.unity 하나입니다. 공용 차량/VFX 프리팹, Graph, Material, 다른 씬은 수정하지 않습니다.

## 사용

1. Hierarchy에서 **DM_CinematicDirector**를 선택합니다.
2. Inspector의 **Timing**에서 원하는 구간 길이를 초 단위로 입력합니다. 위 시간표에 시작/끝과 전체 길이가 자동 표시됩니다.
3. Play하면 차량 주행부터 마지막 재가속까지 자동 진행합니다. Main Camera가 Game 화면을 출력합니다.
4. Play 중 수정한 값은 **변경값으로 처음부터 다시 재생** 버튼을 눌러 적용합니다. Unity Play 중 변경한 값은 Play 종료 시 사라지므로 최종 값은 정지 후 입력하고 씬을 저장하세요.
5. Unity Pause 버튼으로 일시정지합니다. 마지막 구간이 끝나면 차량 연출은 해당 위치에서 유지됩니다. 반복 재생은 자동 루프가 아니라 다시 재생 버튼으로 합니다.

## 시간과 동작의 관계

- 각 구간의 **길이**만 바꾸세요. 뒤 구간 시작 시각은 자동 합산합니다.
- 재생 시작 시 값의 복사본을 사용합니다. 재생 도중 시간을 고쳐도 진행 중인 동작은 갑자기 역행하지 않습니다. 다시 재생하면 변경값으로 전체 순서를 재구성합니다.
- 길이는 안전하게 0.1~120초로 제한합니다. 아주 짧은 구간은 시각적으로 읽기 어렵습니다.
- 보넷 구간 길이를 바꾸면 기존 3.6초 동작을 그 구간 안에 비례해서 배치합니다. 내부의 열림→상승→돌출→연기→발사 순서는 유지하며 원본 설정을 변경하지 않습니다.
- Slow Motion Rate는 촬영용 차량/미사일과 연결된 VFX에 적용합니다. 전역 Time.timeScale은 바꾸지 않습니다. 별도 오디오나 다른 애니메이션을 추가하면 별도 연결이 필요합니다.
- Race Speed Kph, Drop Back Metres, Blue Lead Metres, Red Drift Lag Metres, Boost Extra Kph는 촬영 동선 조절값입니다. 물리 주행 AI가 아니라 반복 촬영을 위한 위치/회전 제어입니다.
- Fit Opening To Timing을 켜면 첫 구간 시간·속도에 맞춰 고정 카메라 01/02 시작 위치를 재생 시작 때 맞춥니다. Ground Camera Offset / Rear Camera Offset으로 위치를 보정합니다. 재생 중 두 카메라는 고정입니다.

## 아직 촬영용 보완이 필요한 부분

- **눈빛:** 운전자 모델/애니메이션은 없습니다. 해당 시간에는 기존 창문 근접 샷이 나옵니다.
- **실내:** 현재 빨간 차는 차체/창문이 통합 메시이고 촬영용 실내가 준비되지 않았습니다. Interior Camera Ready는 기본 OFF이며 실내 구간을 탑뷰로 대체합니다. 실내 준비 후 ON하면 10번 카메라를 사용합니다.
- **창문 통과:** 빨간 차 아래 DM_PassengerWindow_Path / DM_DriverWindow_Path가 입구/출구입니다. 해당 Transform 로컬 위치를 조절하세요. 경로를 연결한 것이며 유리 파손, 운전자 회피, 차체 충돌 판정은 구현하지 않았습니다. 지붕이나 원본 메시는 숨기거나 삭제하지 않습니다.
- **VFX:** 기존 타이어 연기·빨간 부스터를 씬에 복제/언팩해 연결합니다. 원본 프리팹을 수정하지 않지만 Graph/Material 참조는 공유되므로 공유 자산 파일을 직접 수정하지 마세요.
- 카메라/조명/실내/연기 디테일을 최종 영화 품질로 다듬는 작업은 별도 시각 검수가 필요합니다. 현재 연결은 20초 전체 동작과 컷을 반복 확인하는 촬영용 초안입니다.

## 제어 충돌 방지

전체 감독이 활성화된 동안 기존 DMRaceOpening과 보넷 시퀀스는 수동 제어 모드로 넘겨 이중 이동/이중 발사를 막습니다. 개별 카메라 버튼 대신 Director 시간표를 사용하세요. 공유 차량의 이동 스크립트는 수정하지 않습니다. 다른 Timeline/주행 시스템을 연결할 때는 이 Director를 끄고 제어 주체를 하나로 정하세요.
