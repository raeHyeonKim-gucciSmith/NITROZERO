# 02 추월 위협 · 진로 견제 — 카메라 독립 주행 버전

대상: Assets/03DAMIN/DM_avoidMissile_Cinematic.unity

## 재생

Play 정지 → Assets > Refresh → 컴파일 완료 → DM_CinematicDirector의 개별 촬영 / 카메라 2 / 02 독립 테이크 ON → Play.
이 버전은 02 전용 코드만 교체하므로 씬의 기존 렌즈·속도·길이·출발 위치 값은 보존합니다.
영상 파일은 Unity Recorder 또는 화면 녹화 도구로 별도로 저장합니다.

## 기본 8초 연출

- 0–1.3초: 카메라가 차량보다 느리게 이동해 최대 12m 뒤처집니다. 빨강이 화면 깊숙이 멀어지고 파랑이 차선을 벌리며 접근합니다.
- 1.3–2.9초: 파랑이 빨강의 뒤쪽 측면까지 접근합니다. 카메라는 바깥쪽 사선으로 전진하면서 두 차의 앞/뒤 연결부를 봅니다.
- 2.75–3.25초: 빨강이 작은 진로 변경으로 먼저 견제 의도를 보입니다.
- 3.25–4.2초: 파랑이 감속합니다. 앞뒤 간격이 다시 열린 뒤 빨강이 진입 공간을 닫습니다. 차체를 밀어붙이거나 충돌시키지 않습니다.
- 4.2–5.5초: 카메라가 파랑의 감속을 따라가지 않고 전진해 파랑이 프레임 뒤로 물러납니다.
- 5.5–8초: 뒤로 시야를 넓혀 카키를 드러내며 다음 촬영으로 연결합니다.

카메라 위치는 파랑차를 기준으로 붙어 다니지 않습니다. 별도의 촬영 경로를 따르고 조준만 반응 지연을 가집니다.
초반 12m 지연은 FOV 확대/축소가 아닌 실제 상대 이동입니다. 이후 카메라가 따라붙으며 근접 견제 구도로 전환합니다.
행동축의 같은 바깥쪽을 유지합니다. 견제 순간에는 짧고 작은 회전 진동만 추가합니다.
카메라 전환 없이 하나의 연속 8초 테이크입니다.

## 인스펙터 조절

- 녹화 길이: 5–10초. 차량·카메라 동작을 함께 늘이거나 줄입니다.
- 촬영용 속도: 기본 560km/h. 다른 SHOT 속도 배율과 독립입니다.
- 렌즈: 기본 28mm. 24–35mm 범위이며 망원으로 올리면 근접 구간의 차량이 더 잘릴 수 있습니다.
- 노면 위 카메라 높이: 기본 1.1m. 접근 중 0.55m, 후반 공개 시 추가 0.65m가 더해집니다.
- 견제 반응 지연: 차량을 보는 방향의 지연이며 파랑에 카메라를 다시 묶는 값이 아닙니다.
- 진동 강도: 0이면 진동 없음. 빠르기 대신 진동을 과하게 올리지 않는 것을 권장합니다.
- 촬영 시작 빨간차 X: 기본 1200. 도로 범위를 초과하는 속도·길이·출발점 조합은 경고하고 정지합니다.

Play 중 변경 후에는 '변경값으로 처음부터 다시 재생'을 누릅니다.
유지할 값은 Play 정지 후 다시 입력하고 씬을 저장하세요.

## 변경하지 않은 부분

01 독립 촬영, 03–10과 전체 시간표, 차량 크기·저장된 높이, 원본 씬, 공용 차량/VFX 프리팹, 맵·지형·도로·조명·색감.
서브 3대는 카키보다 뒤에 유지하며 일반 레이싱에 드리프트 연기를 추가하지 않습니다.
