# 총알 공기 왜곡 — 재사용 프리팹

## 사용법

1. `Reusable/Prefabs/PF_BulletAirDistortion_Reusable`를 원하는 씬에 넣습니다.
2. `따라갈 총알`에 Hierarchy의 총알 루트를 연결합니다. 모형 Renderer가 그 아래에 있어야 합니다.
3. `촬영 카메라`에 실제 Unity Camera를 연결합니다. Cinemachine 가상 카메라가 아니라 실제 출력 Camera입니다.
4. Play합니다. 배경 이미지는 연결하지 않습니다. 카메라에 보이는 씬을 실시간 촬영하여 굴절합니다.

프리팹은 총알의 이동·활성 상태, 카메라 추적·FOV, 씬이나 URP 프로젝트 설정을 변경하지 않습니다.
기존 테스트 미사일을 사용한다면 기존 `CinematicAirDistortion`만 끄고 테스트 이동/추적은 유지합니다. 같은 총알에 기존 왜곡과 새 왜곡을 동시에 켜지 마세요.
VFX 루트는 씬에 별도로 둡니다. 총알 아래에 넣지 않습니다. 전체 차량/플레이어가 아닌 총알만 Target으로 지정합니다.

## 기본 Inspector

- 왜곡 강도: 0이면 표시/배경 촬영을 멈춥니다. 1이 기본입니다.
- 효과 크기 배율: 자동 측정된 총알 크기를 기준으로 전체 크기를 조절합니다.
- 꼬리 길이 배율: 뒤쪽 왜곡 길이만 조절합니다.
- 잔상 유지 시간: 총알 비활성화/삭제/Detach 후 마지막 위치에서 효과가 사라지는 시간입니다. 기본 0.2초입니다.

## 자동 처리

- MeshRenderer/SkinnedMeshRenderer 모형의 크기와 중심을 읽습니다. ParticleSystem/TrailRenderer/LineRenderer는 크기 계산에서 제외합니다.
- 스케일 변화는 실행 중 반영합니다. 모형 자식 자체를 교체했다면 `RefreshTarget()` 또는 Inspector의 다시 읽기 버튼을 사용합니다.
- 첫 방향은 가장 긴 모형 축으로 추정합니다. 이동을 시작하면 위치 변화로 방향을 판단합니다. 거꾸로 향한 모형은 고급 설정의 초기 방향 자동 감지를 끄고 Forward Axis를 지정합니다.
- 카메라와 총알 크기로 왜곡 평면을 모형 뒤에 배치하여 모형 자체가 뒤틀리는 것을 방지합니다.
- 대상 변경 시 이전 잔상을 초기화하고, 대상이 사라지면 짧게 페이드합니다. 재활성화/풀링도 처리합니다.
- 카메라 교체/해상도 변경 시 캡처를 갱신합니다. 효과는 연결된 카메라에서만 표시됩니다.
- 속도 연동은 기본 OFF입니다. 슬로모션으로 천천히 움직여도 왜곡 강도가 유지됩니다.

## 런타임 생성 총알

```csharp
using Damin.VFX.AirDistortion.Reusable;

// 씬의 VFX 컴포넌트 또는 Instantiate한 VFX 컴포넌트
airVFX.Bind(spawnedBullet.transform, actualCamera);

// 종료: VFX 오브젝트는 TrailFade 동안 살아 있어야 잔상이 남습니다.
airVFX.Detach();
```

컴포넌트/프리팹 자체를 비활성화하면 즉시 종료하고 캡처 리소스를 정리합니다. 총알 게임플레이 스크립트는 포함하지 않습니다.

## 지원 범위 및 비용

- Unity 6.3 / 현재 프로젝트 URP 3D Universal Renderer 기준.
- 단일 Base 카메라, 전체 Viewport, 원근 및 직교, 옆/비스듬한 촬영 지원.
- XR, 카메라 Stack, 분할 Viewport, TAA, 2D Renderer는 이 버전에서 지원하지 않습니다. Inspector와 런타임 상태에 이유를 표시하고 왜곡을 끕니다.
- 총알 정면에서 진행 방향과 시선이 거의 겹치면 길쭉한 왜곡이 퇴화하므로 표시하지 않고 안내합니다. 정면 충격파는 별도 연출입니다.
- Screen Space Overlay UI는 촬영되지 않습니다. 배경은 카메라가 보는 Quad/모형/월드 오브젝트를 사용합니다.
- 카메라가 보는 씬을 효과 1개당 추가로 1회/프레임 렌더링합니다. 영화용 한 발 기준이며, 다수 탄환에는 공유 캡처 최적화가 추가로 필요합니다.
- 카메라의 URP 렌더러를 따라가지만 프로젝트별 커스텀 Renderer Feature/특수 포스트 효과는 별도 검증이 필요합니다. 기본 후처리는 최종 카메라에 맡겨 중복 적용을 피합니다.
- 굴절은 화면 안의 배경만 사용합니다. 화면 밖 정보는 복원하지 않습니다.
- 작은 반투명 구름/발광을 추가하는 효과가 아닙니다. 무늬 없는 단색 배경에서는 변화가 거의 보이지 않는 것이 정상입니다.

## 파일 구성

프리팹 1개 + 런타임 스크립트 1개 + 전용 Inspector 1개 + 전용 셰이더/재질입니다.
테스트 모형, 이동 스크립트, 배경, 카메라, 이전 Cinematic 코드에 대한 의존성은 없습니다.
같은 프로젝트의 다른 씬에는 프리팹을 드래그하면 됩니다. 다른 프로젝트에는 Reusable 폴더 전체와 필요한 URP 패키지를 함께 가져갑니다.
