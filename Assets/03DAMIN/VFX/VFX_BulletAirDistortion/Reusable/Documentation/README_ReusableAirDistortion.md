# 총알 왜곡 프리팹 — 독립 3컴포넌트
공용 위치: Assets/Prefabs/VFX/PF_BulletAirDistortion_Reusable.prefab

## 연결은 한 곳에서
프리팹을 씬으로 드래그하고 ReusableBulletAirDistortion의 '따라갈 총알'과 '촬영 카메라'를 연결합니다.
Camera는 실제 Unity Camera입니다. Cinemachine 가상 카메라를 연결하지 않습니다.
배경은 따로 연결하지 않습니다. 카메라에 보이는 월드 배경을 자동 촬영해 굴절합니다.

## 두 가지 사용 모드
| 컴포넌트 | 테스트 시연 | 실제 게임 |
|---|---|---|
| ReusableBulletAirDistortion | ON | ON |
| AirPreviewFlight | ON | OFF |
| AirPreviewCameraFollow | ON | OFF |

왜곡 Inspector의 '테스트: 이동·추적 ON' / '게임: 이동·추적 OFF' 버튼으로 전환할 수 있습니다.
각 컴포넌트 체크박스로 독립 전환도 가능합니다. 안전을 위해 프리팹 기본값은 두 테스트 컴포넌트 OFF입니다.

## 테스트 모드
- 총알 모형 프리팹 파일 또는 씬의 테스트 총알을 연결하고 카메라를 연결합니다.
- 테스트 ON 후 Play하면 총알이 기본 0.72m/s로 오른쪽으로 이동하고, 카메라는 처음의 상대 위치·회전·FOV를 유지하며 따라갑니다.
- 이동 속도/거리(기본 4m)/방향/반복/대기 시간을 AirPreviewFlight에서 조절합니다.
- 프리팹 파일은 런타임 복사본을 만들어 사용합니다. 공용 Bullet 원본 파일에는 변경을 저장하지 않습니다.
- 게임 스크립트/Rigidbody/Camera가 포함된 프리팹 파일은 실수로 동작시키지 않도록 복사 테스트를 거절합니다. 모형 전용 프리팹 또는 씬의 테스트용 총알을 사용하세요.
- 물리 이동 중인 씬 총알도 테스트 이동을 거절합니다. 기존 이동 스크립트와 이 테스트 이동을 동시에 켜지 마세요.
- 추적 기능과 기존 Cinemachine/카메라 추적기를 동시에 켜면 충돌할 수 있습니다. 테스트할 카메라는 하나의 추적기만 사용하세요.
- OFF 시 런타임 복사본은 제거하고 원래 Target 참조로 돌아갑니다.
- 씬의 총알/카메라는 기본적으로 테스트 시작 전 위치·회전으로 복원합니다. 각 컴포넌트의 RestoreOnDisable을 끄면 현재 위치를 유지합니다.
- 반복 시 시작 위치로 돌아갑니다. 이는 테스트 루프이며 게임 발사/충돌/데미지 기능이 아닙니다.
- 총알이 거꾸로 보이면 '정렬 앞뒤 반전'을 켜세요.
- 카메라가 총알을 처음부터 바라보도록 구도를 먼저 잡으세요. 추적은 화면 구도를 유지하며 위치만 옮깁니다.

## 게임 모드
- 이동·추적 OFF, 왜곡 ON.
- '따라갈 총알'에는 프리팹 원본 파일이 아니라 실제 발사되어 씬에 생성된 총알을 연결합니다.
- 기존 게임 코드가 총알 이동 및 카메라를 담당합니다.
- 런타임 생성 연결: airVFX.Bind(spawnedBullet.transform, actualCamera);
- 종료: airVFX.Detach(); VFX는 TrailFade(기본 0.2초) 동안 살아 있어야 잔상이 남습니다.
- 총알과 VFX 루트는 별도 오브젝트로 둡니다. Target에 전체 차량이나 VFX 자신을 넣지 마세요.

## 왜곡 조절 및 자동화
- 기본 조절: 왜곡 강도 / 효과 크기 배율 / 꼬리 길이 배율 / 잔상 시간.
- 모형 크기·중심을 자동 측정하고 스케일 및 카메라/해상도 변경에 대응합니다.
- Target 교체 시 잔상을 정리하고 비활성화/삭제 시 페이드합니다.
- 슬로모션에서도 기본 왜곡 강도는 유지됩니다. 필요할 때만 고급 설정의 속도 연동을 켭니다.
- 자식 모형 자체를 교체한 경우 RefreshTarget() 또는 모형 다시 읽기 버튼을 사용합니다.

## 지원 범위
Unity 6.3 / URP 3D Universal Renderer, 단일 Base 카메라, 전체 Viewport, 원근/직교, 옆/비스듬한 촬영.
XR, Camera Stack, TAA, 2D Renderer, 분할 Viewport는 제외하고 경고합니다.
Screen Space Overlay UI는 왜곡되지 않습니다. 카메라가 보는 월드 배경을 사용하세요.
정면 촬영에서는 길쭉한 꼬리가 퇴화하므로 표시하지 않고 안내합니다.
효과 1개당 화면을 추가로 1회/프레임 촬영합니다. 다수 총알에는 공유 캡처 최적화가 필요합니다.
특수 Renderer Feature/후처리는 프로젝트별 검증이 필요합니다.
기존 왜곡과 새 왜곡을 같은 총알에 중복 적용하지 마세요.

공용 Bullet.prefab, 팀원의 발사 코드, 기존 테스트 씬은 이 변경의 수정 대상이 아닙니다.
