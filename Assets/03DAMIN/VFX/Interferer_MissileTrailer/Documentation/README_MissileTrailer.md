# 방해자 차량 미사일 트레일러 프리팹

## 사용할 프리팹

- 차량 전체: `Prefabs/PF_Interferer_MissileTrailer.prefab`
- 비행 기능 포함 미사일: `Prefabs/PF_TrailerMissile.prefab`
- 미사일 모델 원본은 기존 `Assets/03DAMIN/Bullet/Prefabs/PF_Bullet.prefab`입니다. 수정하지 않았습니다.

`DaminCar`와 `VFX` 씬의 기존 차량을 `Interferer_MissileTrailer_ROOT`로 교체했습니다. 기존 차량의 위치·회전·크기·활성 상태를 유지하며, `VFX`의 차량 루트와 양쪽 뒷바퀴/중심점 연결은 새 차량으로 이전했습니다. 연기 시간·강도 설정은 변경하지 않았습니다.

## 사용 방법

1. Play 모드로 들어가 Game 뷰를 클릭합니다.
2. Shift: 보넷 열기 → 발사대 상승 → 0.25초 대기 → 4번 미사일만 3cm 상승(0.35초) → 0.4초 대기 → 4번 1발 발사. 나머지 3발은 장착 상태를 유지합니다.
3. 발사 간격이 지난 후 Shift를 다시 누르면 남은 다음 미사일이 발사됩니다.
4. 새 차량의 `03_보넷_미사일발사시스템`을 선택합니다. Inspector의 `처음 상태로 복원 + 4발 재장전` 버튼으로 다시 시작합니다.

## Inspector 설정

같은 `03_보넷_미사일발사시스템`에 두 컴포넌트가 있습니다.

### Trailer Hood Deployment

- Open Angle: 보넷이 열리는 추가 각도. 기본 30도(기존 설정).
- Open Duration: 보넷 열리는 시간. 기본 0.8초.
- Delay After Hatch: 보넷 열린 후 발사대 상승 전 대기. 기본 0.1초.
- Lift Offset: 발사대 상승량. 기본 기존 동작과 같은 0.025m.
- Lift Duration: 발사대 상승 시간. 기본 0.7초.
- Hinge Axis In Vehicle: 차량 기준 회전축. 차량을 회전/이동해도 함께 따라갑니다.

### Trailer Missile Launcher

- 연출 시작 지연: Shift 또는 Play 자동 연출 시작 이후 대기.
- 발사대 전개 후 준비 시작까지: 전개 완료 이후 개별 미사일 준비를 시작하기 전 대기. 기본 0.25초.
- 기본 첫 발사: 시작 후 약 2.60초(보넷 0.8 + 전개 대기 0.1 + 발사대 상승 0.7 + 준비 대기 0.25 + 미사일 상승 0.35 + 상승 후 대기 0.4).
- 한 번에 발사할 수: 기본 1. 4로 설정하면 한 번의 연출에서 4발 순차 발사.
- 발사 순서: 장착 위치 번호 1~4. 기본 4,1,2,3.
- 다음 발사 준비까지 간격: 실제 발사 후 다음 발의 준비 시작까지. 기본 0.5초. 개별 상승 대상이면 그 발의 상승·대기 시간이 추가됩니다.
- 발사 전 개별 미사일 상승 사용: 끄면 개별 상승/대기 단계를 생략합니다.
- 별도 상승시킬 미사일 번호: 기본 4. 발사 순서와 독립적이며 선택 번호에만 추가 상승이 적용됩니다.
- 미사일 추가 상승 높이 (cm): 기본 3cm. 차량 위쪽으로 상승합니다. Unity 1단위=1m 기준이며 부모 스케일을 보정합니다.
- 미사일 상승 시간 (초): 기본 0.35초. 0이면 즉시 상승합니다.
- 올라온 뒤 대기 시간 (초): 기본 0.4초. 0이면 상승 후 바로 발사합니다.
- 상승·대기 중에는 차량/발사대를 따라가고 실제 발사 순간에만 분리됩니다. 도중 재장전하면 상승 전 위치로 복원됩니다.
- 발사구 이탈 전진 거리/상승 높이/시간: 보넷 앞쪽 틈으로 빠져나오는 초기 경로.
- 이탈 후 초기 속도/가속도/유지 시간: 차량에서 떨어져 나온 이후 비행.
- Play 시작 시 자동 연출: 트레일러 촬영용 자동 시작.

이것은 트레일러용 시각적 비행입니다. 적 추적, 대미지, 충돌/피격, 네트워크 동기화는 포함하지 않습니다. 차량이나 장착 위치, 보넷 각도를 크게 바꾸면 초기 이탈 경로도 다시 확인하세요.

## 부품 정리

01 차체/범퍼/도어, 02 바퀴/타이어/브레이크, 03 보넷/미사일, 04 외장장갑/무장/장식, 05 위치별 기계 구조, 06 유리/램프, 07 실내, 08 볼트/너트로 분류했습니다.

이름으로 검색하는 기존 바퀴 스크립트를 보존하기 위해 `tire_001_R17`, `rim_1421` 접두사는 유지하고 앞/뒤·좌/우 설명을 추가했습니다. Cube/Cylinder처럼 정확한 기능을 단정할 수 없는 부품은 임의로 엔진/발사기라고 이름 붙이지 않고 위치와 형상으로 분류했습니다. `PartNames.csv`에서 이전 이름과 새 이름을 비교할 수 있습니다.

기존 보넷 스크립트의 각도/시간/상승량은 읽어서 새 독립 컴포넌트에 옮겼습니다. 원본 스크립트는 수정하지 않았습니다. 새 복사본의 시작 보넷 자세는 원본 FBX의 닫힌 자세로 맞췄습니다.

## VFX 연결

이번 추가는 장착/전개/발사와 연결점 준비입니다. 기존 완성된 VFX 그래프나 프리팹을 수정하거나 자동으로 붙이지 않았습니다.

- `07_VFX연결점_기존효과미변경`: InteriorSmokePoint, LeftVentPoint, RightVentPoint, LaunchBurstPoint.
- 각 미사일의 `02_ExhaustPoint_추진VFX연결`: 미사일 뒤쪽, 로컬 +Z는 배기 방향입니다. 여기에 추진 VFX를 붙이면 발사 후 미사일과 함께 이동합니다.
- Launcher 이벤트: On Sequence Started, On Bay Ready, On Missile Launched, On Sequence Finished, On Reset.
- Missile Flight 이벤트: On Launched, On Flight Ended.
- Timeline/다른 스크립트에서 `PlaySequence()`, `FireNext()`, `ResetAndReload()`를 호출할 수 있습니다. `FireNext()`는 발사대 전개 후 유휴 상태에서 다음 1발의 준비를 요청합니다. true는 요청 수락이며 실제 발사는 선택한 상승·대기가 끝난 뒤 `On Missile Launched` 이벤트로 알립니다. 준비 도중 중복 요청은 무시합니다.
