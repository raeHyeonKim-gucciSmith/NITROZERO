# 보넷 · 미사일 통합 연출

## 어디서 조절하나요?

Final 차량의 **최상위 오브젝트**를 선택합니다. `Hood Missile Sequence Controller` 안의 **보넷 · 미사일 통합 연출**만 조절하면 됩니다. 보넷·발사대·VFX의 기존 하위 스크립트는 내부 동작 담당으로 유지했고, 해당 Inspector에는 통합 컨트롤러로 이동하는 버튼을 표시합니다.

차량 모델, 바퀴, 장착 위치, VFX 그래프는 이번 구조 변경에서 수정하지 않았습니다. 뒷바퀴 연기는 이 컨트롤러와 별개입니다.

## 시간 기준

전체 시작 지연이 끝난 순간을 **0초**로 봅니다. 열림 시작, 발사대 상승 시작, 개별 미사일 상승 시작, 실제 발사 시각, 내부·좌우 연기 시작은 모두 이 0초 기준입니다. 각 항목의 소요 시간은 그 동작이 끝날 때까지 걸리는 시간입니다.

예: 보넷 0초 시작 / 0.8초 동안 열림 → 발사대 0.9초 시작 / 0.7초 동안 상승 → 4번 미사일 5.75초 시작 / 0.35초 동안 3cm 상승 → 6.5초 발사. 미사일 상승 완료 후 대기는 자동으로 계산해 표시하며, 예시에서는 0.4초입니다.

발사 후 연기 유지·감소와 미사일 추진 연기 시작 지연은 **실제 발사 순간 기준**입니다. 발사 순간 VFX도 실제 선택한 미사일의 발사 이벤트에 연결됩니다.

미사일 통이 보넷 열림보다 먼저 움직이거나 미사일 상승 완료 전에 발사하도록 설정하면 경고와 함께 재생을 거부합니다. 입력 시간을 몰래 뒤로 미루지 않습니다.

## Inspector 구역

1. **보넷 열림**: 시작 시각, 소요 시간, 각도.
2. **미사일 통 상승**: 시작 시각, 소요 시간, 높이(cm, 차량 로컬 기준).
3. **미사일 상승 · 발사**: 발사할 1~4번 선택, 해당 미사일만 먼저 올릴지, 상승 시각·시간·높이(cm), 실제 발사 시각.
4. **미사일 비행**: 발사 직후 이탈 경로의 시간·거리, 이탈 후 초기 속도와 가속도, 발사부터 계산하는 비행 수명.
5. **보넷 안에 고이는 연기**: 시작 시각, 차오르는 시간, 밀도·덩어리 크기·발생량.
6. **좌우 틈으로 새는 연기**: 시작 시각, 풍성해지는 시간, 밀도·크기·발생량·흐르는 속도.
7. **미사일 뒤 흰 연기 하나**: 사용 여부, 실제 발사 후 시작 지연, 굵기·밀도·팽창·길이·색.
8. **발사 순간 · 발사 후 잔연기**: 발사 순간 강도, 내부·좌우·잔연기의 발사 후 유지/감소 시간.

고급 항목에는 입자 수명·흔들림·발생량 상한과 기존 내부 연결을 모았습니다. 발생 위치와 충돌 프록시는 기존 `08_보넷미사일VFX` 안에 그대로 있습니다.

## 재생과 저장

- Unity **Play 모드**에서 `재생`, `일시정지/계속`, `처음으로 / 4발 재장전` 버튼을 사용합니다. Shift도 재생/일시정지 후 계속을 실행합니다.
- 한 번의 연출은 **선택한 미사일 한 발**입니다. 재생 중 Shift를 다시 눌러도 중복 발사하지 않습니다. 다시 처음부터 재생하면 4발을 재장전합니다. 이전의 배치 후 연속 한 발씩 발사하는 Shift 동작 대신 트레일러 한 컷 단위로 동작합니다.
- 일시정지는 보넷, 미사일 이동, 연결된 연기 입자를 함께 멈춥니다. 초기화는 보넷·발사대를 닫고 미사일 4개와 연기를 원상복구합니다.
- 시간표와 비행 설정은 재생·일시정지 중 잠깁니다. 초기화한 뒤 변경하세요. 연기의 양·모양은 재생 중 시험 조절할 수 있습니다.
- **Play 중 수정한 값은 Play 종료 시 Unity가 되돌립니다.** 최종 값은 Play를 끈 뒤 입력하고 저장하세요.
- 전체 차량에 적용할 기본값은 Final 프리팹을 열어 최상위에서 수정합니다. 씬 차량에서 수정하면 그 씬의 Override입니다. 의도 없이 Apply All 하지 마세요.
- DaminCar 씬의 기존 이탈 시간 2초와 개별 미사일 대기 0.2초를 통합 설정에 보존했습니다. VFX 씬의 기존 차량 인스턴스들도 그대로 유지했습니다.
- 차량에 장착된 보넷/미사일 연기는 통합 설정을 따릅니다. 독립 VFX 프리팹은 기존 자체 Inspector를 그대로 사용할 수 있습니다.
