# Bullet / TAURUS 미사일 Unity 에셋

## 사용

- 프리팹: `Assets/03DAMIN/Bullet/Prefabs/PF_Bullet.prefab`
- DaminCar 씬의 `Bullet_ROOT`는 차량 옆에 별도로 배치한 프리팹 인스턴스입니다.
- 프리팹 전체를 이동·회전·스케일 조절하면 됩니다. LOD 내부 오브젝트를 개별적으로 이동하지 마세요.
- 단위는 미터이며 길이는 약 0.99m입니다. 루트 원점은 모델 중심입니다.
- 기존 차량의 발사/보넷 스크립트에 연결하지 않았습니다. 자동 발사, 충돌, 물리 이동 기능도 추가하지 않았습니다.

## 경량화

원본 Bullet.blend의 몸체만 약 193만 삼각형이었습니다. 가까운 촬영에서는 디테일을 보존하고, 먼 거리에서는 LODGroup으로 가벼운 메시를 사용합니다.

| 단계 | 전체 삼각형 | 역할 |
| --- | ---: | --- |
| LOD0 | 259,999 | 근거리/클로즈업 |
| LOD1 | 43,000 | 중거리 |
| LOD2 | 11,388 | 원거리 |

각 단계는 몸체, 발광 코어, LED, 유리의 4개 렌더러입니다. 동시에 모든 LOD가 렌더링되는 구조가 아닙니다. 많은 미사일을 한꺼번에 근접 촬영한다면 별도 성능 측정과 더 가벼운 모델이 필요합니다.

- FBX만 사용하므로 팀원의 PC에 Blender를 설치할 필요가 없습니다.
- 텍스처는 2K, 밉맵/압축을 사용합니다. 메시와 텍스처의 런타임 Read/Write는 꺼져 있습니다.
- 원본 Blender의 카메라·조명·불필요한 애니메이션은 가져오지 않았습니다.
- Collider, Rigidbody, 게임플레이 스크립트가 없으므로 기존 차량의 물리 동작에 개입하지 않습니다.

## 재질과 주의점

Unity 6000.3.18f1 / URP 17.3에서 검증했습니다. 몸체의 Blender 색상 처리는 베이크한 BaseColor와 Metallic/Smoothness 맵으로 옮기고, 원본 노멀 맵을 활용했습니다.

유리는 URP Lit 투명 재질로 근사했습니다. Blender의 실제 굴절과 완전히 같지는 않습니다. 발광 코어도 Unity용으로 변환했으며, 주변 조명·노출·Bloom 설정에 따라 보이는 밝기가 달라집니다. 다른 씬의 조명이나 전역 Volume은 수정하지 않았습니다.

`Materials`의 Body, Glass, LED, Energy 재질을 독립적으로 조절할 수 있습니다. 이 폴더의 재질은 기존 차량/VFX 재질과 공유하지 않습니다.
